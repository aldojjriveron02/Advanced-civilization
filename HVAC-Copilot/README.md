# HVAC AI Copilot

Phone-first field copilot for HVAC technicians. The HVAC intelligence core is kept separate from the client interface so the same system can serve iPhone first and future Meta wearable/AI interfaces.

## Milestone 0 — foundation
- Field-first product direction
- Core/interface separation
- Initial domain model contract
- Initial API boundary
- iPhone field workflow
- Meta-compatible architecture boundary
